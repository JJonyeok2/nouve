# Nouve Image Asset Folder

Store all Nouve local image assets here.

Recommended structure:

```text
public/assets/nouve/
  hero/
  products/
  collections/
  editorial/
```

Rules:

- Use descriptive lowercase filenames.
- Prefer `.jpg` for photos and `.png` only when transparency is needed.
- Record every asset in `docs/assets/image-sources.md`.
- Do not commit unlicensed marketplace or brand campaign images.
